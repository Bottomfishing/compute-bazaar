这个文件夹是「算力集市」产品重新开发的工作区。所有代码、截图、决策记录都放这里。

当前已实现交易、受邀 Docker CPU/GPU 工作台、JupyterLab + NumPy、PyTorch CUDA 终端、手动成果归档与跨订单文件恢复。已在 RTX 5050 Laptop 验证真实 CUDA 矩阵和梯度计算，详见 [PyTorch 指南](app/docs/pytorch-guide.md)。归档保存成功后免费保留 7 天，可以下载，也可以在新订单预览后恢复，重名另存副本，详见 [成果恢复指南](app/docs/restore-guide.md)。已进一步加入可查看日志、手动停止、最长 10 分钟的 Python 任务，详见 [任务指南](app/docs/task-guide.md)。下一步重点是独立机主故障演练与 GPU 长任务验证，目前没有真实支付或公网运营能力。

## 三步开始

1. 打开一个新的 AI 编程会话（Cursor / Claude Code / Codex 等能读写文件的工具）。
2. 把 `算力集市-开发提示词.md` 里 **第 3 节「完整开发提示词」整段**复制给它，并补充一句：
   > 工作目录是 `C:\Users\wb198\Desktop\算力集市开发\app`，先把目录建好；现在只做阶段 1，先给我实现计划，不要写代码。
3. 它给出计划后，你先看一遍（表结构、接口、页面、风险点），确认可行再让它写代码。

## 硬性规则

- **一次只做一个阶段**。阶段 1 验收通过，才让它做阶段 2；不要一次让它做完整个产品。
- **先计划后编码**。每轮开始让它说清楚"这轮改什么、怎么验证"，做完对照 `算力集市-开发提示词.md` 第 4 节验收清单逐条打勾。
- **每阶段备份**：验收完把 `app/` 压缩成 `app-阶段1-日期.zip` 放回本文件夹。
- **需求变更写下来**：改需求就改提示词文档，再把新版本给它；不要在聊天里口头改，AI 会忘。
- **它会犯错的地方**：金额用浮点、结算不幂等、并发超卖、把模拟算力说成真卡。这几条提示词里都写了，验收时重点抽查。
