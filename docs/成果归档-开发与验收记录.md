## 使用限制与下一步

必须在订单结束前手动保存成功。该功能不自动保存、不会冻结写入中的内核，不是跨文件全局原子快照；先保存并停止文件写入。已结束且没有快照的旧订单无法恢复。现有 agent 需重启加载新增归档协议。

当前没有目录递归、部分文件选择、对象存储、新订单导入恢复或真实存储收费。SQLite 删除为逻辑删除，历史备份可能仍有旧快照；没有宣称物理擦除。数据库仍适用于受控单机内测，上线前要补备份保留、存储监控和独立 Notebook 域隔离。

GPU 工作台仍仅验证设备识别；本轮没有完成 CUDA/PyTorch 计算或训练。下一轮建议固定 GPU 框架镜像与最小张量计算，再增加跨订单文件恢复和独立机主故障演练。详细使用规则见 `app/docs/archive-guide.md`。
