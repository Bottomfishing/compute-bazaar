# 阶段 1.1 与 2a 首个闭环自测

日期：2026-10-29。范围是模拟机器调度，不含真实 GPU、容器或工作台。

已实现：

- 版本化数据库迁移，升级前一致快照；既有账户、账本和订单保留。
- 在线备份命令、健康检查、请求 ID、订单事件记录。
- “我的机器”页面：登记、一次性凭据、在线心跳、逐卡占用、绑定挂牌、凭据轮换和停用。
- mock CLI：注册、10 秒心跳、1 秒取任务、准备延迟/失败注入、模拟启动停止、本地租约看门狗。
- 逐 GPU 唯一分配；离线机器不可租；重复机器挂牌被拒绝。
- 环境 ready 后开始计费；准备中取消、启动最终失败、掉线、停用均全额退款。
- 持久化任务投递与尝试编号；启动最多重试一次；重复或乱序回报不重启已结束订单。
- 结算与清理分离：清理确认前卡位隔离，不能重复分配。
- 前端下单请求幂等，订单页展示准备、运行、失败和清理状态，可查看执行记录。
