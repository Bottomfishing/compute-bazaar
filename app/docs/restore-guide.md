# 跨订单成果恢复指南

## 怎么继续上次的工作

1. 在旧订单结束前保存成果快照，看到“成果快照已保存”后再结束。快照保留 7 天。
2. 租用新的真实 Docker CPU/GPU 订单，环境就绪后打开工作台。沿用受邀内测规则。
3. 在“把历史成果，接到这一单”点击“选择历史成果”，从自己其他订单的未过期快照中选择“预览恢复”。
4. 核对“快照中的文件 → 本单保存为”。重名时生成 `result-restored-xxxxxxxx.txt` 一类的副本名，不覆盖现有文件。请先保存并停止 Notebook、终端和后台程序的文件写入。
5. 点击“确认恢复 N 个文件”。看到“恢复完成”后，文件列表会刷新，可以打开文件或自行执行脚本。重命名后，脚本中的相对文件名可能需要手动调整。
6. 新工作完成后，再次保存成果快照。恢复不会自动生成下一份快照。

尚未保存成功就销毁的旧容器无法补救。已删除或已过期的快照不能恢复；这也不是任意 ZIP 上传入口。

## Notebook 与 GPU

支持已有 Python、JupyterLab + NumPy 和 PyTorch CUDA 工作台。恢复 `.ipynb` 后，在 JupyterLab 左侧文件列表双击恢复的文件；如果和默认 `welcome.ipynb` 重名，会另存为副本。已保存的单元格输出随文件恢复，内核是新进程。代码需要的依赖、GPU 模板和数据必须由用户自行核对。

恢复只复制文件，不重建虚拟环境、运行进程、计算内存、GPU 内存、内核状态或整个容器。不会自动执行代码，也不提供自动断点续训。单条命令仍限 15 秒，原有租金、预付、分成、退款及订单结束销毁规则不变。

## 中断、冲突与重试

- 预览计划最多有效 5 分钟，同时不能超过源快照到期或目标订单结束时间。过期后重新选择并预览。
- 首次确认前再次检查文件。如果目标被修改，停止恢复并报告冲突；不会覆盖不同内容的文件、目录、链接或特殊文件。
- 确认后的断线不代表没有写入。页面会显示“结果待核对”，恢复记录刷新后仍可查看。计划有效期内点击“按原计划重试”，沿用相同目标名；内容逐字节相同的普通文件直接复用，缺少的文件才创建。
- 恢复是逐文件发布。开始发布后发生冲突或进程中断，可能只完成一部分；回执显示新增、复用、冲突及说明。不会通过自动删除文件假装回滚。请核对记录，避免直接新建另一份计划造成多余副本。
- 已完成计划重复确认只返回原回执。回执表示当时的结果，之后用户自行修改文件不会改变该记录。
- 订单结束后不能继续恢复，但租客仍可查询本单恢复记录；源快照删除后，已有恢复记录与已复制文件也不因此删除。

每单最多保留 20 份计划，未确认且过期的计划会在下一次预览时回收。历史快照来源按 20 份分页。文件范围和容量沿用[成果归档规则](archive-guide.md)：100 个顶层可见普通文件、每个 1 MiB、合计 4 MiB；没有目录递归或选择部分文件。工作目录上限仍为 64 MiB，恢复暂存也占用该空间。

## 升级与实现约束

数据库升级至 v5，新表 `order_restores` 保存来源、固定文件映射、状态和回执，不复制快照 BLOB。升级前生成 `data/market.sqlite.before-v5.bak`，保留原账户、订单、归档和账本。启动已有 agent 的机器需要重启同一条接入命令，加载 `agent-0.5.0`；无需重建容器镜像。

控制面只读取自己的既有 stored ZIP：验证整包摘要、清单、文件摘要和限额，并用现有 ZIP 写入器重建逐字节比较。没有通用解压、任意路径或客户端自定义文件正文入口。内部 `restore_probe` / `restore` 消息禁止通过普通工作台 actions 路由调用。

agent 经认证反向连接接收内容，通过 stdin 送入订单容器，避免 Windows 命令行长度限制。以 UID 1000 校验后暂存，使用 [Python os.link](https://docs.python.org/3.12/library/os.html#os.link) 在同一工作目录发布文件，目标已存在时不会覆盖。容器内 12 秒、宿主 15 秒上限；超时或连接断开记录待核对。隐藏暂存文件不归档，容器销毁时一并清理。

接口均要求登录租客；预览和确认还要求当前运行、ready 的真实订单与有效工作台会话：

- `GET /api/orders/:id/restores/sources?offset=0`：自己的其他订单未过期快照，仅返回清单。
- `GET /api/orders/:id/restores`：本单最近 20 份计划和回执，可在订单结束后查询。
- `POST /api/orders/:id/restores/preview`：`{session, archive_id}`，预览并固定文件映射。
- `POST /api/orders/:id/restores/:restoreId`：`{session}`，确认或沿原计划重试。

这是本机受控内测文件恢复，独立机主断网演练、多卡和公网运营仍需另行验证。
